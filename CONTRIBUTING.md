# Вклад в LiteMind Engine

Спасибо за интерес к проекту!

## О проекте

LiteMind Engine — лёгкий локальный движок для ИИ-моделей на слабых Windows-ПК.
Главные ценности: **бесплатность** (0 €, без платных API и подписок), **безопасность
слабых машин** (прогноз памяти, очередь, лимиты) и **честность** (никаких непроверенных
заявлений о скорости — только измерения).

## Чем помочь

- Исправлять ошибки и улучшать тексты документации.
- Добавлять тесты (проект обязан оставаться без «фиктивных» функций).
- Адаптировать под другие backend'и (llama.cpp server и т.п.) через контракт
  `src/backends/base.js` + `registerBackend()`.
- Переводить документацию на английский.

## Как начать

1. Установите [Node.js](https://nodejs.org) 18.17+. Python и C++-тулчейн не нужны.
2. Склонируйте репозиторий и перейдите в папку.
3. `npm install` не требуется — зависимостей нет.
4. Прогоните тесты: `.\scripts\test.ps1` (или `npm test`).
5. Запуск: `.\scripts\start.ps1` → http://127.0.0.1:8399.

Тесты работают на mock-сервере: Ollama и модели для них **не нужны**.

## Правила

- **Не обязательно** ставить Ollama и модели — и никогда не скачивайте их в тестах.
- Не добавляйте платные API, подписки, телеметрию и сбор ключей.
- Не добавляйте зависимостей без необходимости: у проекта их ноль, сохраняйте это.
- Не оставляйте критичные функции в виде заглушек: либо работает, либо честно
  написано «не работает» в README/документации.
- Каждое изменение — с тестами (`npm test` должен оставаться зелёным).
- Заявления о производительности — только с цифрами из `docs/BENCHMARKS.md`.
- Не включайте в репозиторий: секреты, `.env`, логи, `%APPDATA%`-конфиги, веса моделей,
  личные пути и данные.

## Формат коммитов

Короткие сообщения на английском или русском, объясняющие **зачем**, а не что изменено:
`fix: queue slot not released after cancel`, `docs: add Windows install steps`.
