# Установка и запуск на Windows 10/11

## 1. Что нужно

| Компонент | Зачем | Где взять |
|---|---|---|
| Node.js 18.17 или новее | среда выполнения LiteMind | https://nodejs.org (LTS) |
| Ollama | backend выполнения моделей | https://ollama.com/download |
| Модель (1 штука, небольшая) | реальная генерация | `ollama pull <имя>` — **вручную** |

LiteMind не скачивает ни Ollama, ни модели сам. Установка Ollama — ваше явное решение.

## 2. Установка по шагам

1. **Node.js.** Откройте PowerShell и проверьте:
   ```powershell
   node -v      # должно показать v18.17.0 или новее
   ```
   Если команда не найдена — установите LTS с https://nodejs.org и перезапустите терминал.

2. **Каталог проекта.** Перейдите в папку, куда скопирован проект (плейсхолдер):
   ```powershell
   cd "/путь/к/litemind-engine"
   ```

3. **Зависимости не нужны.** В проекте ноль production-зависимостей, `npm install` можно
   не выполнять. (Если очень хочется — `npm install` просто не найдёт что ставить.)

4. **Проверка установки:**
   ```powershell
   node bin\litemind.js doctor
   ```
   Команда покажет: версию Node, путь к конфигурации, активный профиль, состояние Ollama,
   RAM/CPU/VRAM и список локальных моделей. Код возврата `0` — всё в порядке;
   `1` — Ollama не найдена или недоступна.

5. **Запуск** (предпочтительно скриптом — он сам подхватит конфиг для слабого ПК):
   ```powershell
   .\scripts\start.ps1
   # или вручную: node bin\litemind.js serve  /  npm start
   ```
   Откройте http://127.0.0.1:8399 — панель управления.

6. **Остановка:** `\scripts\stop.ps1` в другом окне (или `Ctrl+C` в терминале).

## 3. Проверка, что Ollama действительно работает

Выполните (в отдельном окне терминала):

```powershell
curl.exe http://127.0.0.1:11434/api/version
# ожидаемый ответ: {"version":"0.x.x"}

curl.exe http://127.0.0.1:11434/api/tags
# ожидаемый ответ: {"models":[{"name":"...","size":...}, ...]}
```

Если Ollama отвечает — LiteMind её увидит. Если нет: запустите приложение «Ollama» из
меню «Пуск» (иконка в трее) и повторите запрос.

> Ollama в Windows запускается как обычное приложение с иконкой в трее и поднимает
> HTTP-сервер на `127.0.0.1:11434`. LiteMind ничего не устанавливает и не запускает
> вместо вас.

## 4. Установка одной небольшой модели

```powershell
ollama pull qwen2.5:0.5b      # ~400 МБ — хорошо для слабых машин
# или: ollama pull llama3.2:1b
```

Список установленных моделей: `node bin\litemind.js models`.
Никакой автозагрузки моделей в LiteMind нет — запуск только вручную, из панели или API.

## 5. Конфигурация

Файл: `%APPDATA%\LiteMind\config.json` (путь покажет `node bin\litemind.js config`).
При первом запуске файла нет — используются значения по умолчанию; он создаётся, когда вы
что-то сохраняете. Пример минимального содержимого:

```json
{
  "api": { "port": 8399, "host": "127.0.0.1" },
  "backend": { "type": "ollama", "baseUrl": "http://127.0.0.1:11434" },
  "profile": "low"
}
```

После изменения конфигурации перезапустите `npm start`.

## 6. Автозагрузка (по желанию)

LiteMind **сам** себя в автозагрузку не добавляет. Если хотите запускать сервер вместе с
Windows — создайте ярлык на `node bin\litemind.js serve` и поместите его в
`shell:startup`. Учтите: автозагрузка сервера не означает автозагрузку моделей
(`autoLoadAtStartup: false` — модели поднимаются только по запросу).

## 7. Если что-то пошло не так

| Симптом | Что проверить |
|---|---|
| `EADDRINUSE` при запуске | порт занят: `node bin\litemind.js serve --port 8400` |
| «Ollama is not reachable» | запущена ли Ollama (см. раздел 3) |
| Пустой список моделей | `ollama list` в терминале |
| `MEMORY_BUDGET` | в панели видно прогноз; закройте лишние программы или возьмите модель поменьше |
| `QUEUE_FULL` | идёт другой запрос — дождитесь конца или нажмите «Остановить» |
| Панель не открывается | посмотрите журнал в `%APPDATA%\LiteMind\logs` |
| Скрипт `.ps1` не запускается | `Set-ExecutionPolicy -Scope Process RemoteSigned` (для текущего окна) или запуск через `powershell -ExecutionPolicy Bypass -File scripts\...` |

## 8. Обновление

1. Остановите движок: `scripts\stop.ps1`.
2. Замените папку проекта новой версией (или `git pull`).
3. Пользовательские настройки в `%APPDATA%\LiteMind\config.json` **сохраняются** — они
   лежат вне папки проекта/установки.
4. Модели Ollama (`%USERPROFILE%\.ollama\models`) не затрагиваются никогда.
5. Запустите снова: `scripts\start.ps1`.

## 9. Удаление

Способ А — установщик: «Приложения» → «LiteMind Engine» → Удалить. Программа убирается,
настройки и модели остаются (по желанию установщик удалит и настройки — галочка на
странице удаления).

Способ Б — без установщика (просто копия проекта):

```powershell
.\scripts\stop.ps1          # остановить
# затем просто удалите папку проекта в Проводнике
# настройки (по желанию): Remove-Item -Recurse "$env:APPDATA\LiteMind"
# модели Ollama удаляются только вручную: ollama rm <имя>
```
