### 1.2 Зависимости и требования к установке

| Компонент | Нужен? | Примечание |

| npm-пакеты | **нет** | `dependencies: {}`, собирать и ставить ничего не надо |

| Веб-браузер | для панели | любой встроенный |

Вывод для установщика: **нужно проверять только Node.js** (и, по желанию, предупреждать об отсутствии Ollama). Никаких C++/Python-тулчейнов, никаких библиотек «по умолчанию».

## Этап 3. Выбор способа сборки установщика

Критерии: 0 евро, без облака, без интернет-зависимости при сборке, ставится офлайн,
работает на Windows 11 x64, умеет обновлять и корректно удаляться.

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **Inno Setup** | бесплатный (BSD-лицензия), полный контроль: выбор папки, ярлыки, проверки, запись в «Установка и удаление программ», сохранение пользовательских файлов при обновлении, офлайн-установка, скрипт — обычный текст | требует установленного компилятора `ISCC.exe` (бесплатно), которого на целевом ПК **нет** — пришлось бы доустанавливать программу | запасной |
| **NSIS** | бесплатен (Zlib-лицензия) и **уже установлен на целевом ПК** (`C:\Program Files (x86)\NSIS`): выбор папки, ярлыки, проверки, офлайн-установка, записи в «Приложения», необязательные компоненты, uninstaller с пользовательскими данными отдельно | синтаксис `.nsi` менее читаемый, чем Inno | **выбран** |
| MSI/WiX | «родной» формат Windows | нужен WiX Toolset (не установлен), избыточно для Node-проекта | отклонён |
| electron-builder | — | не подходит: у нас нет Electron | отклонён |
| Скрипты `.ps1` без установщика | уже есть (Этап 2) | не даёт ярлыков и записи в реестр удаления | остаются как способ «без установщика» |

**Итог: NSIS** — единственный бесплатный инструмент, уже присутствующий на машине
(бюджет 0 €, никаких новых программ ставить не нужно). Скрипт: `installer/litemind.iss`
→ фактически `installer/litemind.nsi`, сборка: `makensis installer\litemind.nsi`.
Inno Setup остаётся резервным вариантом, если позже понадобится MSI-подобный UX.

### Требования к установщику (чек-лист ТЗ) и как они закрываются

| Требование | Реализация в `installer/litemind.nsi` (NSIS) |
|---|---|
| Выбор папки пользователем | страница `MUI_PAGE_DIRECTORY`, по умолчанию `$LOCALAPPDATA\Programs\LiteMind Engine` (установка без прав администратора) |
| Проверка архитектуры | в `.onInit`: `${RunningX64}`, иначе сообщение «Нужна 64-битная Windows» и прерывание; `MinVersion` = 10.0.19045 (Windows 10 22H2) |
| Проверка зависимостей | в `.onInit`: `nsExec` запускает `node -e "...>=18?0:1"`; если Node нет или старше 18 — понятное сообщение с ссылкой на nodejs.org и вопрос «Продолжить без Node.js?» |
| Не требовать Python | проверки на Python нет по определению (см. 1.2) |
| Ярлык запуска | «LiteMind Engine» → `powershell.exe -ExecutionPolicy Bypass -File "$INSTDIR\scripts\start.ps1"` |
| Ярлык/команда остановки | «Остановить LiteMind Engine» → `stop.ps1` (мягкая остановка через API, затем только свои PID) |
| Сохранение конфигурации при обновлении | `%APPDATA%\LiteMind\config.json` лежит **вне** папки установки — установка поверх и обновление его не трогают; файлы в `$INSTDIR` заменяются |
| Не удалять модели | модели в `%USERPROFILE%\.ollama\models` установщик не трогает ни при установке, ни при удалении |
| Не запускать Ollama сам | ни одного запуска Ollama в установщике; только информационное сообщение, если её нет |
| Не скачивать модели | установка полностью офлайн, сетевых загрузок нет |
| Корректное удаление | uninstaller в «Приложения»/«Удаление программ»; удаляет только `$INSTDIR`; отдельная (по умолчанию выключенная) галочка «Также удалить мои настройки» трогает только `%APPDATA%\LiteMind` |
| Без секретов и личных данных | список файлов задан явно: `bin/ src/ config/ scripts/ README* LICENSE CHANGELOG`; `test/ docs/ installer/` не входят |
| Понятные ошибки об отсутствии зависимостей | русские сообщения с точной ссылкой, что установить |
| Не встраивать большую модель | в установку входит **только** исходный код (~1 МБ); ни одной модели |

### Состав будущей установки

```
LiteMind Engine/
  bin/  src/  config/  scripts/   ← код проекта (без test/, docs/, installer/)
  README.md  LICENSE  CHANGELOG.md
  (ярлыки)  LiteMind Engine · Остановить LiteMind Engine · Документация
```

Размер установки: **< 5 МБ** (без моделей). Пользователь сам ставит Node.js и Ollama.
