# Changelog — LiteMind Engine

Формат: Keep a Changelog; версионирование SemVer.

## [0.3.0] — 2026-11-07

### Added
- **Adaptive Engine** (`packages/litemind-engine/src/adaptive/`):
  - контроллер сложности запроса (simple/file/project/hard) и адаптивный бюджет генерации;
  - умное уплотнение контекста (система/первая задача/недавние сохраняются; середина — сводка);
  - extractive-дайджест длинных входов;
  - честная карта возможностей runtime (`/api/capabilities`);
  - Project Context: инкрементальный индекс и поиск по проекту (`/api/project/scan|search|map`).
- **Автооптимизация модели** (`/api/optimize`): замер tokens/sec и TTFT по конфигурациям
  потоков, сохранение лучшей; живые метрики EMA в профиле модели.
- **Защита Windows**: memory-gate, контроль памяти во время генерации (MEMORY_OVERLOAD →
  автостоп + безопасная выгрузка), приоритеты процессов Ollama по профилю.
- **Профиль «Производительный»**; профиль по умолчанию — «Сбалансированный» (ТЗ §6).
- **Нативные экраны LiteMind внутри Desktop** (`packages/app/src/litemind/`):
  Мои модели, Каталог моделей, Загрузки, Железо, Мониторинг, Настройки —
  в одном окне, без браузера и `127.0.0.1:8399`-переходов.
- **Автозапуск движка внутри Electron main** (`packages/desktop/src/main/service/litemind-host.ts`).
- **Windows-установщик**: NSIS с выбором папки, ярлыками «LiteMind Engine», portable-версия;
  фирменная иконка.
- GitHub Actions: тесты движка + сборка Windows x64 (`litemind-windows.yml`).
- Документация: `docs/litemind/{ARCHITECTURE,ADAPTIVE-ENGINE,BUILD-WINDOWS}.md`.

### Changed
- Сайдбар LiteMind открывает внутренние экраны приложения вместо веб-панели.
- Брендинг: LiteMind (title, productName, артефакты, иконки).
- Каталог: 12 проверенных HF-моделей (0.5B–7B GGUF, uncensored-метки), рекомендуемый
  квант под конкретное железо.

### Fixed
- Загрузчик: прогресс через Transform (сохранение backpressure), корректные пауза/отмена,
  докачка Range; контроль размера файла.
- Совместимость: импорт `resource/gate.js` после переезда каталогов; корректный
  `totalRamMb` в отчёте железа.
- Тесты изолированы от CWD (конфиг больше не пишется в рабочий каталог).
