    Команды

    «Остановить все модели» — генерации отменяются, модели выгружаются из RAM/VRAM, приложение продолжает работать. «Остановить движок» — дополнительно останавливаются загрузки и сервер движка; приложение остаётся открытым. «Выход» — сначала останавливает все процессы LiteMind, затем закрывает приложение.

    Выбрать модель по задаче

    —

    Что означают термины: GGUF, Q4/Q5/Q8, контекст, память

    GGUF — формат файла модели для локального запуска (один файл содержит всё: алгоритм, словарь, веса). LiteMind работает только с GGUF — другие форматы не скачивает.

    Q4, Q5, Q8 (квантование) — насколько «сжаты» веса модели. Q4 — файл примерно в 4 раза меньше оригинала, качество немного ниже, зато модель быстрее и занимает меньше памяти. Q5 — компромисс. Q8 — почти без потери качества, но файл и память почти как у оригинала. Правило: сначала пробуйте Q4_K_M, если хватает памяти — берите Q5_K_M/Q6_K.

    Контекст — сколько текста модель «видит» одновременно (в токенах). Больше контекст — больше памяти: подсказки и длинные документы требуют запаса.

    Память при запуске ≠ размер файла — модель занимает в RAM больше, чем весит файл: веса × ~1,15 + кэш контекста + служебные данные. LiteMind показывает оценку заранее, чтобы модель не «съела» весь компьютер.

    AVX/AVX2 — инструкции процессора, ускоряющие ИИ. У процессоров Intel Celeron N5095A их нет; сборка LiteMind работает и без них — просто медленнее.

    Загрузки

    Поддерживается докачка: пауза и обрыв сети сохраняют файл .part, «Продолжить» докачает с места остановки.

    Проекты

    —
    —
    открыт

    Закрытие просто убирает проект из активных: файлы на диске не удаляются и не изменяются.

    Проекты LiteMind не хранит: сканирование строит карту файлов и индекс для поиска. Последние папки запоминаются локально.

    Исключения сканирования

    Папки через запятую, которые не показывать в дереве и не искать (node_modules, .git и служебные исключаются всегда).

    Недавние проекты

    «Убрать из списка» удаляет проект только из этого списка — файлы на диске не затрагиваются. Недоступные папки честно помечаются.
