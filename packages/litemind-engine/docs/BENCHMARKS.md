### Как получить эти числа у себя (после установки Ollama и одной модели)

```powershell
# 1) установите Ollama с https://ollama.com/download и одну небольшую модель:
ollama pull qwen2.5:0.5b

# 2) убедитесь, что backend жив:
curl.exe http://127.0.0.1:11434/api/version

# 3) запустите LiteMind в одном окне:
npm start

# 4) в другом окне — автоматические замеры:
node scripts/benchmark.mjs --model qwen2.5:0.5b --n 3
```

Скрипт измеряет и печатает готовую строку для таблицы выше: TTFT, общее время,
токенов/сек, RAM до/пик/после выгрузки, время освобождения памяти. Полученные значения
впишите в раздел 3.1 этой страницы.

## 4. Ограничения, подтвержденные измерениями

1. **Сбор метрик дорогой** (~0.9 с на Windows) — опрос ограничен раз в 2 с и не блокирует
   работу; при желании частоту можно снизить в `resource.pollIntervalMs`.
2. **VRAM приблизительная**: `AdapterRAM` у Windows не сообщает фактическое занятое
   состояние, поэтому панель показывает «≈ N MB (всего)», а не свободную видеопамять.
   Точный недоступный объём через стандартные средства Windows не получить.
3. **Прогноз памяти эвристический** (веса + 64 КБ/токен на KV-кэш + 256 МБ): точный
   расчёт требует знаний об архитектуре конкретной модели, которых Ollama в `/api/tags`
   не отдаёт. Поэтому рядом с отказом всегда показывается прогноз и бюджет.
4. **Нет обещаний об отсутствии зависаний**: измерить отзывчивость системы под нагрузкой
   модели на этой машине невозможно, пока модели нет.
